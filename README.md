# Анализ лояльности пользователей Яндекс Афиши

Этот проект создан для трансформации логики исследовательского анализа (EDA) в структурированное Python-приложение. Главная цель репозитория — хранить и автоматически воспроизводить все этапы предподготовки данных и статистического анализа поведения пользователей Яндекс Афиши, которые изначально были разработаны в Jupyter Notebook.

---

## Цели и задачи проекта
* **Цель:** Спроектировать архитектуру приложения на базе ООП (класс `DataProcessor`) для автоматизации анализа транзакций.
* **Задачи:**
1. Выгрузить данные с помощью SQL-запроса.
2. Провести очистку и предобработку данных (обработка выбросов, конвертация валют).
3. Сформировать профили пользователей.
4. Рассчитать метрики лояльности и провести корреляционный анализ.
5. Сформулировать выводы и рекомендации для бизнеса.

---

## Функционал класса DataProcessor
Ядром приложения является модульный класс `DataProcessor`. Функционал класса включает:
* Безопасное подключение к БД SQL через переменные окружения (`.env`), выгрузка датафреймов с помощью SQL-запросов и их объединение с локальными данными курсов валют (CSV).
* Автоматическая корректировка типов данных, очистка от аномалий (отсечение выбросов по 99-му перцентилю) и конвертация стоимости покупок из иностранной валюты в рубли по историческому курсу.
* Формирование профиля каждого пользователя — определение его первого региона, устройства, жанра мероприятия, расчет общего числа заказов и среднего чека.
* Вычисление доли вернувшихся клиентов по сегментам и расчет коэффициента phi_k для поиска признаков, сильнее всего коррелирующих с лояльностью пользователя.

## Инструкция по запуску
1. Клонируйте репозиторий:
```bash
git clone https://github.com/RIPeBaNan/mle-analiz-loyalnosti-polzovatelej.git
cd mle-analiz-loyalnosti-polzovatelej
```

2. Установите зависимости (рекомендуется использовать виртуальное окружение (venv)):
```bash
pip3 install -r requirements.txt
```

3. Настройте переменные окружения:
В корне проекта создайте файл .env на основе файла .env.example и укажите данные для подключения к БД:
```text
DB_USER= # Введите имя пользователя базы данных
DB_PWD= # Введите пароль пользователя базы данных
DB_HOST= # Введите хост базы данных
DB_PORT= # Введите порт базы данных
DB_NAME= # Введите имя базы данных
CURS_CSV_PATH= # Введите путь к файлу с курсами валют. Может быть локальный путь или ссылка на файл в интернете
```

4. Запустите обработку: 
Исполняемый файл `main.py` инициализирует экземпляр класса DataProcessor, прогонит данные через методы и выведет в консоль итоговый аналитический отчет.

---

## Формат вывода
При запуске `main.py` класс DataProcessor загрузит логи в оперативную память и сгенерирует консольный отчет. Отчет включает в себя:
* Объем обработанной и отфильтрованной аудитории.
* Средний проент возврата клиентов.
* Топ-сегменты пользователей (по регионам, устройствам, мероприятиям) с наивысшим процентом лояльности к сервису.
* Основные признаки, которые влияют на возвращаемость клиентов.
